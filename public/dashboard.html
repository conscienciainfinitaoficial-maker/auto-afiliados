⚙️ Pendiente: Base de Datos

Los leads se guardan en memoria temporal. Para que persistan:

  1. 1. Andá a supabase.com → "New project"
  2. 2. Copiá Project URL y Service Role Key (Settings → API)
  3. 3. En SQL Editor, ejecutá el contenido de supabase-schema.sql
  4. 4. En Vercel → Settings → Environment Variables, agregá: SUPABASE_URL=tu-project-url
    SUPABASE_SERVICE_KEY=tu-service-role-key
  5. 5. Redeploy en Vercel
